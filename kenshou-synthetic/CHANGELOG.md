# Changelog

## 0.1.0.0 - 2026-10-28

### New Features

- First public release of the synthetic reference suite, a layer built only on the generic packages that exercises every extension point: migration sets, worker roles, a registered oracle, advisory labels, pool methodology, routing rules, and a named resource.
- Five scenarios cover correctness under kill and restart, disjoint lease ownership, an open-loop benchmark, a soak for leak diagnosis, and a resource round trip.
- Provides the standalone `kenshou` executable.

### Other Changes

- New in this repository; the suite it verifies is the harness itself.
